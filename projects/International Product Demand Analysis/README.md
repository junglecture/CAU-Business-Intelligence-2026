# International Product Demand Analysis

Business Intelligence — Fall 2026 · Chung-Ang University

## Project overview

This project investigates whether country-specific product recommendations match future purchases better than a global best-seller list.

The objective is to help e-commerce businesses determine whether product recommendations should be standardized globally or localized by country.

## Code and reproducibility

Planned implementation structure:

- `data/`: Dataset documentation
- `src/ranking/`: Global and country-specific ranking methods
- `src/evaluation/`: Train/test split and evaluation metrics
- `app/`: Streamlit dashboard

Setup and execution instructions will be added once the implementation is ready.
